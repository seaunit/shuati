# 拾题本地测试环境

## 分支与环境隔离

- 测试代码在独立 `test` 分支，不修改生产 `main` 分支的部署配置。
- 生产服务器仍从 `main` 部署，本地测试不会自动影响线上。
- 本地密钥只保存在被 Git 忽略的 `.env.local` 和 `payments/.env`。
- AI 使用现有正式 API Key；邮件和支付使用测试模式。

## 桌面快捷方式

- `启动拾题测试环境`：启动 MySQL、Redis、后端、Waffo 测试支付侧车和前端，并打开应用。
- `停止拾题测试环境`：停止本地应用进程，不停止系统 MySQL / Redis 服务。
- 首次启动如果系统服务未运行，Windows 会请求一次 UAC 权限。

启动后会同时打开：

- 应用：<http://127.0.0.1:5173/app/>
- 测试日志窗口：显示模拟邮件验证码、关键后端错误和支付侧车日志

## 邮件模拟

- `SHUATI_MAIL_ENABLED=true`
- `SHUATI_MAIL_SIMULATE=true`
- 不连接真实 SMTP。
- 注册、找回密码等验证码输出到测试日志窗口。

## Waffo 测试支付

- 使用测试私钥，密钥只保存在 `payments/.env`。
- `WAFFO_ENV=test`
- `WAFFO_DRY_RUN=false`
- 商品映射使用 Waffo 测试商品。
- 测试卡：
  - 成功：`4576 7500 0000 0110`
  - 失败：`4576 7500 0000 0220`
  - 使用任意未来有效期和 CVC。

## 切换分支

```powershell
# 进入测试版本
git switch test

# 回到生产版本
git switch main
```

切换分支前建议先执行“停止拾题测试环境”快捷方式。
