### 几个关键实现细节

1. **公开页面不走 SPA**。百度蜘蛛对 JS 渲染支持很弱，所以首页、题库页、单元页、
   题目详情页都由后端直接输出完整 HTML，页面里自带 canonical、面包屑和结构化数据。
2. **统计代码要装在直出页面上**，不能只装 SPA 外壳 —— 自然搜索的落点几乎都在直出页面，
   装在 SPA 里等于看不见搜索流量。
3. **GSC 与百度的站点验证文件放在 `frontend/public/`**，随每次部署自动带到站点根目录，
   不会因为重新部署而失效。
4. sitemap 由后端动态生成（跟着数据库走），**新增题库/单元/题目会自动包含**，
   不用重新提交；每条 URL 都带 `lastmod`，Google 会据此安排重抓。

### 遇到并解决的问题（这部分可能比结果更有价值）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 百度蜘蛛「DNS 无法解析 IP」 | 解析记录刚生效，蜘蛛侧缓存了旧的解析失败 | 等缓存过期后重试，公网各解析器（含百度自己的 180.76.76.76）实测均正常 |
| 百度蜘蛛「Robots封禁」 | Cloudflare 的「Bot Preference Sync」把 Baiduspider 写进了 robots.txt 的 `Disallow: /`，而 robots.txt 在边缘缓存 4 小时 | 在 Cloudflare 把 Training 策略改为 Allow，再清 robots.txt 缓存 |
| GSC sitemap 显示「无法抓取」 | 提交的那一刻正好赶上后端重新部署，源站返回 5xx | 重新读取站点地图，恢复为「成功 / 484 页」 |
| 页面 TTFB 1.5 秒 | 上海 → Cloudflare 伦敦节点握手约 570ms，另加回源约 900ms | 给直出页面加 `Cache-Control`，让边缘缓存掉回源那一段 |

### 分组与承接策略

**A 组｜考试信息类**（软考是什么、报名条件、考试时间）
—— 搜索量最大的几个词，但头部位置被官网 `bm.ruankao.org.cn`、百度百科、知乎占据，
我们是工具站，**这一组主动不承接**，投入产出比低。

**B 组｜真题类**（核心流量池）
—— 用户想「找到某套真题并看到答案」。承接页是题库页与单元页，
这两个页面已经有完整题干、选项、答案、解析。**本次优先做这组。**

**C 组｜刷题工具类**（商业调研 / 交易）
—— 用户在选工具，转化意图最强。承接页是首页（讲清楚能做什么 + 免费开始刷题）。

**D 组｜备考方法类**（信息型长尾）
—— 适合用文章承接，先把备考方法写进题库页正文（本次做了），
后续再扩成独立文章。

**E 组｜差异化能力**（竞品没有的）
—— 竞品几乎只做选择题题库；我们有简答题 + AI 按评分要点批改。
「主观题没人给判分」是真实痛点，这一组是我们最该抢的位。

## 任务三：优化 SEO 页面（已完成 `/bank/1`）

### 为什么选这个页面

关键词研究里，**B 组（真题类）是流量池，而 `软考真题` 是这一组最核心的词**；
`/bank/1` 就是这个题库的落地页，而且它已经被 GSC 和百度收录过一次，
优化它比新建页面见效更快。「软考真题」是信息型检索，用户想看到的是**真题和答案**，
而原来的页面只有一串单元名 —— 内容与检索意图不匹配。

## 加分项

### 竞品页面分析表

见上文「竞品与参考资料」表格（6 个真实页面）。

### 从关键词研究里发现的产品优化机会

搜索结果里有多篇「2018~2025 真题 PDF 汇总」「打印版」的博客/资料页排名靠前，
说明相当一部分用户的真实需求是**把题打印出来做**。我们目前只能在线刷，
所以「题库导出 / 打印视图」既是一个 SEO 承接点（软考真题 pdf、打印版），
也是一个能直接留住用户的产品功能，建议排进下一阶段。

### 用过的关键提示词

给 AI 生成 322 道题的解析时，用的系统提示词（与产品内「AI 解析」保持同一套风格）：

> 你是 Java 面试讲师。根据题目、选项和正确答案，输出一段 Markdown 解析。
> 要求：1. 开篇点明正确答案，并说明它为什么正确；2. 逐个选项简述为什么对/为什么错；
> 3. 适当补充面试考点延伸；4. 解析只针对题目本身，禁止提及任何考生的作答、选择或对错；
> 5. 不要用 LaTeX / 数学公式语法，符号用纯文本（例如 P1→P2、O(n)）；6. 300 字以内，直接输出 Markdown。

第 5 条是踩坑后加的：模型第一版输出了 `\(P_i \to P_j\)` 这种 LaTeX，
而页面用的是轻量 Markdown 渲染，不认公式语法，用户会看到原始符号。
