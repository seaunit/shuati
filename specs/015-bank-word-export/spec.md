# Feature Specification: 题库导出 Word

**Feature Branch**: `015-bank-word-export`

**Created**: 2026-10-26

**Status**: Implemented

**Input**: 用户要求为导入题库功能增加导出 Word 文档，并自动完成格式排版。

## User Scenarios & Testing

### User Story 1 - 从题库管理导出一份可直接阅读的 Word (Priority: P1)

有维护权限的用户进入题库管理页，点击“导出 Word”，下载一份包含该题库完整内容的标准 `.docx` 文件。

**Why this priority**: 用户需要把已经导入或手工维护的题库带离系统，用于打印、批注、归档和二次编辑。

**Independent Test**: 创建含两个单元、不同题型、选项、答案和解析的题库；导出后用 Word 解析器读取，确认内容完整且有自动排版。

**Acceptance Scenarios**:

1. **Given** 用户可以维护一个有题目的题库，**When** 点击“导出 Word”，
   **Then** 下载文件名包含题库名，扩展名为 `.docx`，文档可正常打开。
2. **Given** 题库包含多个单元，**When** 打开导出文档，
   **Then** 按单元分组，单元标题清晰，题目使用全文连续编号。
3. **Given** 题目包含单选、多选或简答题，**When** 查看文档，
   **Then** 显示题型、难度、题干、选项、答案和解析；空字段不产生无意义标签。
4. **Given** 题库没有题目，**When** 导出，**Then** 仍生成包含题库信息和“暂无题目”提示的有效文档。

### Edge Cases

- 普通用户尝试导出别人的私有题库：拒绝访问。
- 普通用户尝试导出公共题库：拒绝访问，因为公共题库只有管理员可维护。
- 管理员导出公共题库：允许。
- 题库名包含文件系统非法字符或换行：下载文件名自动安全化。
- 题干或解析包含 Markdown 换行、标题、列表、粗体或代码：文档中保持可读，不直接显示 Markdown 控制符。
- 超长题库：导出按顺序生成，不调用 AI，不扣点数。

## Requirements

### Functional Requirements

- **FR-001**: 题库维护页 MUST 提供明确的“导出 Word”入口。
- **FR-002**: 导出 MUST 使用题库维护权限，不得放宽现有本人/他人/管理员权限边界。
- **FR-003**: 文档 MUST 为可被 Microsoft Word 和 WPS 打开的 `.docx` 格式。
- **FR-004**: 文档 MUST 包含题库名称、描述、导出时间、单元标题和题目内容。
- **FR-005**: 每道题 MUST 显示题型、难度、题干、答案和解析；选择题有选项时按 A/B/C 等顺序展示。
- **FR-006**: 文档 MUST 使用 A4 纸张、合理页边距、中文字体、标题层级和题间留白自动排版。
- **FR-007**: 空题库 MUST 生成有效文档和明确空状态提示。
- **FR-008**: 下载文件名 MUST 安全、包含题库名，并使用 `.docx` 后缀。
- **FR-009**: 导出 MUST NOT 修改题库、练习记录或点数。

### Key Entities

- **题库**：名称、描述、所有者、公共/私有属性。
- **单元**：题库内的排序分组。
- **题目**：题型、题干、选项、答案、难度、解析、上下架状态。

## Success Criteria

- **SC-001**: 用户可从题库管理页一次点击完成下载，无需额外参数或二次确认。
- **SC-002**: 自动化测试读取生成文件后，能验证题库、单元、至少三种题型、选项、答案和解析均存在。
- **SC-003**: 本人可导出、他人不可导出、管理员可导出公共题库的权限矩阵全部通过。
- **SC-004**: 前端下载交互测试、后端文件内容测试和前端生产构建全部通过。

## Assumptions

- 导出范围是整个题库，不按当前题目列表的搜索词或上下架筛选导出。
- 文档是题目与答案解析合一的“题库资料版”，不是考试时使用的无答案试卷。
- Markdown 只做轻量可读化处理；远程图片不下载，保留其文字链接以避免访问未知地址。
