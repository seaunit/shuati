# Feature Specification: 截图导入题库（粘贴板图片 → AI 生成题目）

**Feature Branch**: `009-screenshot-import`

**Created**: 2026-10-21

**Status**: Implemented（识图通道：沿用现有单条 AI 配置的多模态能力）

**Input**: 用户要求 —— 「导入题库增加截图导入功能，就是根据 AI 根据截图里的文字信息生成题目，使用粘贴板中的截图」。

## 问题与目标

现在导入题库支持三种来源：粘贴正文、网页链接、上传文档。用户手上经常只有**题目截图**
（题库 App、PDF 阅读器、聊天记录里的图片），要先手动打字才能导入，门槛很高。

目标：在导入页直接 **Ctrl+V 粘贴截图** → 识别文字 → 走现有的「AI 拆题 → 预览勾选 → 导入到题库」链路，
和文档导入体验一致（异步任务、进度、可导入到已有题库）。

## 硬约束（来自现状）

- 当前唯一的 AI 配置是 DeepSeek，**纯文本模型，不支持图片输入**，不能直接把图丢给现有 `AiClient`；
- 用户此前要求「AI 配置只维护一条」，所以**不建议再加一条视觉模型配置**；
- 识别结果必须回到现有 `import_task` 流程，不另起一套导入链路；
- 点数计费沿用文档解析口径（按识别出的字数算），不新增计费规则。

## Requirements *(mandatory)*

- **FR-001**: 导入页 MUST 新增第 4 种来源「截图识别」，与「粘贴正文 / 网页链接 / 上传文档」并列。
- **FR-002**: 该模式下 MUST 支持在页面内 **Ctrl+V 粘贴剪贴板图片**，同时 MUST 支持点击选择本地图片
  （jpg/png/webp），单张 ≤ 5MB。
- **FR-003**: 粘贴后 MUST 显示缩略图预览，并允许「移除重贴」；未选图时提交 MUST 被拦住并给中文提示。
- **FR-004**: 后端 MUST 新增一个截图导入入口：接收图片（base64）+ 目标题库信息，先做**文字识别**，
  再把识别文本写入现有 `import_task`（kind=screenshot），交给现有异步拆题任务处理。
- **FR-005**: 识别失败 MUST 返回可读错误（如「截图里没识别到文字，换一张清晰点的」），MUST NOT 建空任务。
- **FR-006**: 识别出的文本 MUST 进入导入任务详情页，用户可在预览里勾选/取消题目后再导入（沿用现有交互）。
- **FR-007**: 单张截图识别出的文字 MUST 有长度上限（默认 20000 字），超出截断并提示。
- **FR-008**: 识图服务凭证 MUST 只放服务器环境变量（`/etc/shuati/env`），MUST NOT 进仓库、MUST NOT 下发前端。
- **FR-009**: 计费 MUST 沿用 EXTRACT 的按字数计费；识图失败时不扣点。
- **FR-010**: 识图通道 MUST 可配置、可关闭（关闭时前端隐藏「截图识别」入口并给出说明）。
- **FR-011**: 四种来源（粘贴正文 / 网页链接 / 上传文档 / 截图识别）MUST 共用同一套「资料 → 题目」
  规则：资料里是现成题目就原样抽取；是讲解、笔记或知识点就据此生成可练习的题目，
  答案 MUST 来自资料本身，不得编造资料外的信息。
- **FR-012**: 网页来源 MUST 在抓取前读取站点 `robots.txt`，按本站 UA（`ShuatiBot`）判定；
  明确 `Disallow` 的页面 MUST NOT 抓取，MUST 返回 403 并提示改用「截图识别」。
  `robots.txt` 404 视为允许；返回 4xx/5xx 或无法解析时 MUST 保守拒绝。
  抓取 MUST 做 SSRF 防护：仅 http/https，禁止本机 / 内网 / 链路本地 / 云元数据地址，
  重定向 MUST 逐跳复检；抓取 UA MUST 可识别（`ShuatiBot/1.0`）。

## 决策（已定）

**沿用现有单条 AI 配置的多模态能力**：DeepSeek Flash 已支持图片输入，不再引入 OCR 服务、
也不新增第二条视觉模型配置（符合"AI 配置只维护一条"）。

- `AiClient.chatWithImage()` 同时支持 OpenAI 与 Anthropic 两种协议的图片消息格式
  （OpenAI：`image_url` data URL；Anthropic：`image` base64 block）；
- 截图直接交给模型出题（看图 + 按 `EXTRACT_SYSTEM` 的 JSON 结构输出），不先转文字再二次调用；
- 计费按「1 万字等价」一次扣 10 点，失败全额退回；
- 图片限制：PNG/JPG/WebP，解码后 ≤ 5MB。

## Success Criteria

- **SC-001**: 在导入页 Ctrl+V 粘贴一张题目截图 → 出现缩略图 → 提交 → 任务轮询到完成 → 预览里出现题目。
- **SC-002**: 截图里有多道题时，能拆出多道（以现有拆题能力为准），可勾选后导入到已有题库。
- **SC-003**: 纯色/无文字图片提交后返回「没识别到文字」提示，且不产生空任务、不扣点。
- **SC-004**: 关闭识图开关时，前端不显示该模式，接口返回 503 可读提示。
- **SC-005**: 识别出的文本按字数计入现有 EXTRACT 计费，账本记录可查。
- **SC-006**: `robots.txt` 全站禁止时，网页导入返回 403 与「改用截图识别」提示；
  按路径禁止时只拒绝该路径；允许的页面正常抓取。内网地址与 `ftp://` 一律拒绝。
