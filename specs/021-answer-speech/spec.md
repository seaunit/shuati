# Feature Specification: 答案与 AI 解析语音朗读

**Feature Branch**: `test`

**Created**: 2026-10-27

**Status**: Ready

**Input**: User description: "对答题后的参考答案和 AI 解析区域开启完整版语音朗读功能，先改测试环境。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 朗读答题反馈 (Priority: P1)

用户在提交答案后，可以点击朗读按钮，按顺序听到参考答案、AI 解析和延伸考点。

**Why this priority**: 这是核心价值，让用户在通勤、休息或阅读疲劳时也能复习答案。

**Independent Test**: 提交一道题后点击朗读，确认开始播放、句子高亮、暂停和继续均正常。

**Acceptance Scenarios**:

1. **Given** 页面已展示参考答案或 AI 解析，**When** 用户点击“朗读”，**Then** 从第一段正文开始播放。
2. **Given** 正在播放，**When** 用户点击“暂停”，**Then** 当前句子暂停且高亮保留。
3. **Given** 已暂停，**When** 用户点击“继续”，**Then** 从暂停的句子继续播放。
4. **Given** 正在播放，**When** 用户点击“停止”，**Then** 播放结束、高亮清除并回到可重新播放状态。

---

### User Story 2 - 控制语速和阅读范围 (Priority: P2)

用户可以选择适合自己的语速，并控制是否跳过代码块。

**Why this priority**: 不同用户对听读速度的偏好差异较大，代码块直接朗读体验较差。

**Independent Test**: 调整语速到多个档位并重新播放，确认语音速度变化且代码内容默认被跳过。

**Acceptance Scenarios**:

1. **Given** 朗读面板已显示，**When** 用户选择 `0.75x`、`1x`、`1.25x` 或 `1.5x`，**Then** 后续句子使用新语速。
2. **Given** 文本包含代码块，**When** 默认模式开始朗读，**Then** 代码块不逐字朗读，只提示“此处有一段代码”。
3. **Given** 用户开启“朗读代码”，**When** 播放到代码段，**Then** 朗读代码的简化文本。
4. **Given** 设备同时存在本地中文音色和名称含 Online/Natural 的在线音色，**When** 用户打开音色选项，**Then** 只展示本地音色，不展示已知依赖网络的音色。

---

### User Story 3 - 稳定处理异常和切题 (Priority: P3)

用户在切换题目、切换浏览器窗口或设备不支持中文语音时，能够获得明确且可控的行为。

**Why this priority**: 语音功能不能干扰刷题进度，也不能让用户误以为系统卡死。

**Independent Test**: 播放时切换题目、刷新页面或模拟无可用语音环境，确认播放停止且界面有明确状态。

**Acceptance Scenarios**:

1. **Given** 正在朗读，**When** 用户切换上一题、下一题或做其他跳转，**Then** 当前朗读自动停止。
2. **Given** 浏览器不支持语音合成，**When** 用户进入答题反馈区域，**Then** 不显示可操作的朗读按钮并提供简短说明。
3. **Given** 设备没有中文语音，**When** 用户尝试播放，**Then** 停止播放并提示设备缺少中文语音。
4. **Given** 用户选择的在线音色合成失败，**When** 设备还存在其他可用中文音色，**Then** 系统从音色列表中移除失败音色、自动切换到下一个可用音色并继续朗读当前内容。

5. **Given** 正在朗读，**When** 用户切换到其他浏览器窗口或标签页，**Then** 语音继续播放，不主动取消。

### Edge Cases

- 超长解析分句后逐段播放，不得一次性提交整篇长文本。
- Markdown 标题、列表符号、链接地址不得被逐字朗读。
- 连续点击播放/暂停不能产生重叠语音。
- 浏览器窗口或标签页隐藏时不得主动取消语音；如果浏览器或操作系统自行终止语音，状态必须复位。
- 同一题目多次重新生成解析后，朗读内容必须使用最新解析。
- 在线自然音色可能出现在浏览器列表中但实际合成失败；失败音色不得反复出现在当前会话的音色选项里。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在答题提交后的参考答案和 AI 解析区域提供“朗读”入口。
- **FR-002**: 系统 MUST 支持播放、暂停、继续、停止和重新开始。
- **FR-003**: 系统 MUST 按句子或语义段拆分内容，并高亮当前正在朗读的句子。
- **FR-004**: 系统 MUST 提供 `0.75x`、`1x`、`1.25x`、`1.5x` 四档语速。
- **FR-005**: 系统 MUST 将 Markdown 转成适合听读的纯文本，去除标题符号、列表符号和链接目标。
- **FR-006**: 系统 MUST 默认跳过代码块，并提供“朗读代码”开关。
- **FR-007**: 系统 MUST 默认使用简体中文语音，并在播放前检查语音能力。
- **FR-008**: 切换题目、离开页面或重新生成解析时，系统 MUST 停止当前朗读。
- **FR-009**: 系统 MUST NOT 自动播放语音，必须由用户主动触发。
- **FR-010**: 系统 MUST 在无语音能力或中文语音不可用时显示明确提示。
- **FR-011**: 朗读功能 MUST 同时适用于网页端和 Capacitor 打包的 Android/iOS 壳，不新增后端 API。
- **FR-012**: 所有控制按钮 MUST 支持键盘操作并提供可访问名称。
- **FR-013**: 音色发生语音合成专用错误时，系统 MUST 将失败音色从当前会话选项中移除，并自动切换到其他可用中文音色继续当前句。
- **FR-014**: 系统 MUST NOT 把浏览器自动播放限制误判为音色损坏；此类错误应提示用户再次主动点击朗读。
- **FR-015**: 设备存在本地中文音色时，音色列表 MUST 默认隐藏名称明确标记为 Online/Natural 的网络音色；仅在缺少本地中文音色时保留在线音色兜底。

- **FR-016**: 浏览器窗口失焦、标签页切换或页面进入 hidden 状态时，系统 MUST NOT 主动停止语音；仅在切题、离开刷题页面或组件卸载时停止。

### Key Entities

- **朗读脚本**：从答案与解析中提取的有序句子列表，包含文本、类型和原文位置。
- **朗读状态**：`idle`、`playing`、`paused`、`unsupported`、`error`。
- **朗读偏好**：语速和是否朗读代码，当前会话内保存。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户从提交答案到开始朗读的操作不超过 2 次点击。
- **SC-002**: 播放、暂停、继续和停止在 1 秒内反馈界面状态。
- **SC-003**: 100% 的 Markdown 代码块在默认模式下不会被逐字朗读。
- **SC-004**: 切换题目后，上一题的语音在 1 秒内停止。
- **SC-005**: 自动化测试覆盖正常播放、暂停继续、停止、切题停止和语音不可用五类场景。
- **SC-006**: 网页端与 Android 壳使用同一套朗读组件和交互。

- **SC-007**: 页面从 visible 切换到 hidden 后，当前语音的取消次数不增加，且后续分句仍可继续播放。

## Assumptions

- 本期使用设备系统提供的语音合成能力，不接入付费云端 TTS。
- 朗读范围限定为已提交答案后的参考答案、AI 解析和延伸内容，不朗读题干和选项。
- 语音偏好保存于当前浏览器会话，不跨设备同步。
- 音频硬件、自动播放限制等非音色错误不进入永久隐藏列表。
- 页面必须由用户手势触发播放，避免浏览器自动播放限制。
- 桌面浏览器通常允许窗口隐藏后继续语音合成；Android/iOS 壳切后台是否继续由系统 WebView/OS 音频策略决定。
- 本阶段只部署和验收测试环境，正式环境待测试通过后再切换。
