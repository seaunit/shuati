# Feature Specification: 背题模式

**Feature Branch**: `018-study-mode`

**Created**: 2026-10-26

**Status**: Implemented

**Input**: 用户要求增加背题模式；开启后直接显示正确答案和 AI 解析，解析库没有内容时自动生成。

## User Scenarios & Testing

### User Story 1 - 开启背题模式后直接看答案 (Priority: P1)

用户在练习页开启背题模式，当前题立即显示正确答案；选择题在选项中高亮正确项，简答题显示参考答案。

**Independent Test**: 开启开关后不提交答案，页面立即显示正确答案，且不产生练习记录。

**Acceptance Scenarios**:

1. **Given** 选择题未作答，**When** 开启背题模式，**Then** 正确选项以绿色标记并显示正确答案。
2. **Given** 已开启背题模式，**When** 切到下一题，**Then** 新题自动显示答案，无需再次点击开关。
3. **Given** 关闭背题模式，**When** 查看题目，**Then** 答案与解析重新隐藏。
4. **Given** 背题模式显示答案，**When** 用户不提交，**Then** 不写 `practice_record`、不增加完成数。

### User Story 2 - 自动补全解析库 (Priority: P1)

题目已有解析时直接显示；没有解析时自动调用 AI 解析并保存到解析库。生成成功后再次进入该题不再重复调用。

**Acceptance Scenarios**:

1. **Given** 题目 explanation 非空，**When** 开启背题模式，**Then** 直接显示已有解析，不调用 AI。
2. **Given** 题目 explanation 为空，**When** 开启背题模式，**Then** 自动生成一次解析并显示生成中状态。
3. **Given** 自动生成失败，**When** 用户重试，**Then** 显示错误并允许手动重新生成。
4. **Given** 用户在生成过程中切题，**When** 旧题响应返回，**Then** 不得覆盖当前题内容。

### Edge Cases

- 背题模式自动生成属于现有收费 AI 功能，必须沿用点数扣费和失败退款。
- 同一题同一次进入只自动请求一次，避免来回切题重复扣点。
- 私有题库仍需遵守现有可见性权限。
- 错题重练、单元练习、题库练习均可使用背题模式。

## Requirements

- **FR-001**: 练习页 MUST 提供清晰的背题模式开关。
- **FR-002**: 开启后 MUST 立即加载当前题正确答案，且不创建作答记录。
- **FR-003**: 选择题 MUST 标记所有正确选项；简答题 MUST 显示参考答案。
- **FR-004**: 解析库有内容时 MUST 直接展示，不重复生成。
- **FR-005**: 解析库为空时 MUST 自动调用现有 AI 解析服务。
- **FR-006**: 自动生成 MUST 复用现有计费、限流、解析库保存和失败退款。
- **FR-007**: 切换题目 MUST 自动展示新题答案与解析。
- **FR-008**: 关闭模式 MUST 清除仅用于背题的答案展示。
- **FR-009**: 自动生成请求 MUST 防止同题并发重复。

## Success Criteria

- **SC-001**: 用户开启背题模式后，无需提交即可看到正确答案。
- **SC-002**: 无解析题目自动生成解析，请求只发生一次。
- **SC-003**: 已解析题目开启模式不触发 AI 请求。
- **SC-004**: 答案 API 对无权访问的私有题库返回 403。
- **SC-005**: 后端测试、前端 E2E 和生产构建通过。

## Assumptions

- 背题模式默认关闭，不跨页面持久保存。
- 自动生成使用现有 `/api/practice/questions/{id}/explanation`，不新增计费规则。
- 正确答案通过独立只读接口获取，普通刷题接口不提前下发 answer。
