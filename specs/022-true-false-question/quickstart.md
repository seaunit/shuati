## 3. 手工验收

1. 登录本地测试环境。
2. 进入“题库管理” → 自建题库 → “新增题目”。
3. 选择题型“判断”，填写题干，选择“正确”并保存。
4. 打开该题开始练习，确认只有“正确/错误”。
5. 选择正确答案提交，确认 10 分且正确项绿色。
6. 编辑题目把答案改成“错误”，再选“正确”提交，确认 0 分且颜色正确。
7. 开启背题模式，确认正确答案显示中文。
8. 导出 Word，确认题型和答案正确。

## 4. 移动端

构建同一份前端产物并打开 App，重复练习和背题步骤。不得出现 App 专属接口或不同答案。
