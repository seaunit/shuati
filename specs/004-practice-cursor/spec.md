# Feature Specification: 练习光标（进度记录"当前刷到哪道题"）

**Feature Branch**: `004-practice-cursor`

**Created**: 2026-10-16

**Status**: Draft

**Input**: 用户要求 —— 「从头开始刷题后，进度不会记录……不管是上一题还是从头开始，
当前刷到哪道题就记录哪道题，不管前面有没有刷过」。

## 背景：现在为什么记不住

现在的"进度"不是记位置，而是**按已作答记录推出来的"第一道没答过的题"**：

- 从第 1 题重刷 → 答完第 2 题退出 → 再进来会跳到"第一道没答过的那道"（可能是第 10 题），
  而不是第 2 题；
- 点「上一题」回到第 5 题退出 → 同样按"没答过的"算，位置记不住。

也就是：**只要题目之前答过，位置就不算数**。用户要的是"光标"语义。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 退出再进，落在我刚刷的那道题上 (Priority: P1)

用户在某个题库/单元里刷题，无论怎么移动（下一页、上一题、从头开始），
退出后再进来，应该停在**他最后停留的那道题**上，而不是"第一道没答过的题"。

**Independent Test**：答一道题 → 从头开始 → 练到第 2 题 → 退出 → 重进，断言停在第 2 题。

**Acceptance Scenarios**：

1. **Given** 从没练过这个范围，**When** 进入练习，**Then** 按老规则落在"第一道没答过的题"
   （老用户的历史进度不丢）。
2. **Given** 光标停在第 2 题，**When** 进入练习，**Then** 直接落在第 2 题，**不管第 1、2 题是否答过**。
3. **Given** 点「从头开始」，**When** 退出再进，**Then** 落在第 1 题。
4. **Given** 点「上一题」回到第 5 题，**When** 退出再进，**Then** 落在第 5 题。
5. **Given** 一轮做完（点「完成练习」），**When** 再次进入，**Then** 从第 1 题重新开始
   （光标清掉，回到"全部答完就重来"的老规则）。
6. **Given** 同一账号在网页端与 App 上，**When** 一端换了题，**Then** 另一端进入时也是那道题。

### Edge Cases

- 光标指向的题已被下架/删除：客户端找不到就回退到"第一道没答过的题"，不报错。
- 错题重练（按 id 组的一轮）：不读也不写光标（那是一次性题集），不受影响。
- 未登录：进度接口本就要求登录，光标同样只在登录后可用。

## Requirements *(mandatory)*

- **FR-001**: 系统 MUST 按「账号 + 练习范围（全部 / 题库 / 单元）」记录一个**光标**
  （当前停留在哪道题），范围与现有进度接口一致。
- **FR-002**: 客户端每次切换当前题（下一题 / 上一题 / 从头开始）MUST 更新光标。
- **FR-003**: 进入练习时 MUST **优先**用光标定位；没有光标时才回退到
  「第一道没答过的题」的旧规则。
- **FR-004**: 一轮做完（完成练习）时 MUST 清掉该范围的光标，使下次进入从第 1 题重新开始。
- **FR-005**: 光标 MUST 属于账号（服务端存储），因此网页端与 App 看到同一份进度。
- **FR-006**: 光标 MUST NOT 放宽权限：只能读写自己的光标；范围要做可见性校验。
- **FR-007**: 旧行为 MUST 保留：没有光标时，"继续上次没刷完的地方"仍然成立。

### Key Entities

- **练习光标（practice_cursor）**：账号 + 范围类型 + 范围 id → 题目 id，外加更新时间。

## Success Criteria *(mandatory)*

- **SC-001**: 用户描述的流程可复现通过：答一题 → 从头开始 → 到第 2 题 → 退出 → 重进落在第 2 题。
- **SC-002**: 后端测试覆盖：写入后读到、范围隔离、跨账号不可见、清空后回退、可见性校验。
- **SC-003**: 网页端 Playwright 覆盖：有光标时按光标落位；切换题目会写光标。
- **SC-004**: 安卓端有等价的纯函数单测（光标优先 / 光标失效回退 / 无光标回退）。
- **SC-005**: 不改变既有接口契约（只新增两个接口 + 一张表）。

## Assumptions

- 光标的粒度是"范围"（题库 / 单元 / 全部），与现有 `scopeType` 一致；不做"每题一个书签"。
- 光标不做历史版本，只保留最近一次位置。
- 错题重练不参与光标（它按题目 id 组题，与范围无关）。
